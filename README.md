# Dream Life App

Life goals tracker + Dream Life Activation, by The Expand Lab.

- `CLAUDE.md`: full context for Claude Code (start here)
- `docs/PRODUCT_BRIEF.md`: the product brief
- `app/`: the Expo app (iOS, Android, web). See `app/README.md`
- `prototype/`: the working web prototype (run `python3 -m http.server 8000` inside it, open http://localhost:8000)
- `design/`: phone-size screenshots of every tab

## Getting started in Claude Code

```
cd dream-life-app
claude
```

Then try: "Read CLAUDE.md and scaffold the Expo app with the design tokens and UI kit."
